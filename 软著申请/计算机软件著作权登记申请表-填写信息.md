## 四、主要功能和技术特点(申请表"软件简介"栏,约 300 字,可直接粘贴)

> 富商笔记软件是一款移动端云笔记应用,采用前后端分离架构,客户端基于 React Native 跨平台框架,服务端基于 Node.js (Express) 框架与 MySQL 数据库,通过 RESTful API 通信。软件主要功能包括:用户注册登录与密码管理、笔记的创建编辑删除与恢复、Markdown 语法编辑与实时预览、笔记收藏置顶、多标签管理与按标签筛选、标题正文关键词搜索、按更新时间/创建时间/标题排序、回收站防误删、编辑草稿自动保存、个人资料与标签管理等。技术特点:客户端使用 JWT 令牌鉴权与会话保持;服务端采用分层架构与统一错误处理,使用参数校验与安全中间件加固接口;数据采用软删除机制保护用户数据;界面采用统一主题与全局消息反馈组件,支持骨架屏加载与空状态提示。
