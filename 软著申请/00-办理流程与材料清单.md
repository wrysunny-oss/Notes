## 二、提交前需要处理的三件事

### 1. 源程序鉴别材料转 PDF(必须)

文件 `富商笔记软件V1.0-源程序鉴别材料.txt` 已按"每页 50 行"分好页,共 60 页。转 PDF 步骤:

1. 用 Word/WPS 新建文档,纸张 A4、页边距默认;
2. **设置页眉**:输入"富商笔记软件V1.0"(页眉右侧可加页码),居中或居右;
3. 将 txt 内容按页粘贴:每 50 行为 1 页,页与页之间用"插入 → 分页符"分页(不要用大量回车,否则行数校验不齐);
4. 正文字体建议 宋体/等宽字体 小四(12pt)或五号,行距 1.0~1.15,确保**每页代码不少于 50 行**;
5. 删除 txt 中每页开头的 `═══════ 第 X 页 ═══════` 分隔行(页码由页眉承担);
6. 另存为 PDF,命名:`富商笔记软件V1.0-源程序.pdf`。

> 检查标准:PDF 总页数 60 页,任意一页正文 ≥ 50 行,页眉有软件名。

### 2. 用户手册补截图(必须)

打开 `富商笔记软件V1.0-软件说明书(用户手册).md`,在 19 处【图 X-X】位置插入截图:

| 截图 | 来源 |
|---|---|
| 登录页 / 注册页 | 浏览器打开 http://localhost:8081 截图,或真机截图 |
| 列表页 / 编辑页 / 回收站 / 设置页 | 登录 demo 账号后逐页截图 |
| 各弹窗(排序/标签/删除确认) | 操作时截图 |

截图要求:清晰、完整、无真实用户隐私数据;可加边框;每页手册正文不少于 30 行(图文混排自然满足)。

同样设置页眉"富商笔记软件V1.0"+页码,导出 PDF 命名:`富商笔记软件V1.0-用户手册.pdf`。

### 3. 替换占位信息(必须)

全部【 】占位内容:公司全称、统一社会信用代码、地址、联系人、邮箱;手册封面著作权人;首次发表日期(如与 GitHub 公开日期不同)。

## 三、办理流程

```
① 注册账号
   ccopyright.com.cn → 用户注册(用公司信息/经办人邮箱)
        ↓
② 在线填报
   登录 → "计算机软件著作权登记申请" → 按本目录"申请表-填写信息"逐项填写
   → 上传:申请表(填报生成)、源程序PDF、用户手册PDF、营业执照PDF
        ↓
③ 提交受理
   提交后等待中心受理,受理后可在线查询状态
        ↓
④ 补正(如被要求)
   若收到补正通知,按通知意见修改后在线重新提交(常见补正原因见第四节)
        ↓
⑤ 发证
   审查通过后发放电子版《计算机软件著作权登记证书》,可在官网下载验证
```

## 四、常见补正原因(避坑)

| 补正原因 | 规避方法 |
|---|---|
| 源程序页眉缺少软件名称或版本号 | 页眉必须与申请表"软件全称+版本号"一字不差 |
| 源程序每页不足 50 行 | 严格按 50 行/页排版,页眉行不计入正文 |
| 源程序内容与开发工具/编程语言不符 | 申请表"开发工具"与"编程语言"按本套信息填写,保持一致 |
| 手册为纯文字无界面截图,或截图与软件功能对不上 | 按本套手册补 19 张实拍截图 |
| 软件名称不规范(如带"APP""系统"字样不统一) | 本套材料统一用"富商笔记软件",全称/简称/页眉保持一致 |
| 营业执照未盖章或不在有效期内 | 副本复印件加盖公章,扫描清晰 |

## 五、费用与周期

| 项目 | 说明 |
|---|---|
| 官方登记费 | 免费(2017 年起取消软件著作权登记费) |
| 官方周期 | 一般 1~2 个月左右出证(以官网公布为准) |
| 加急通道 | 部分代理机构提供付费加急(数个工作日出证),非官方必须项,自行斟酌 |

## 六、证书到手后

- 证书可用于:应用商店上架资质(部分渠道)、高新技术企业认定、软件产品增值税退税、公司知识产权台账等;
- 建议同步登记**:V2.0 及以上版本**每次大版本迭代可申请新版本软著(修改版本号重新走一遍流程);
- 源程序与手册 PDF 自行留档至少 5 年,便于维权时举证。
